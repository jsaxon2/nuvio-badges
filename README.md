# Nuvio badges

Fusion-style stream badge pack for Nuvio, based on [leonevz/Elite-Badges](https://github.com/leonevz/Elite-Badges),
with extra badges for AAC, MP3, Mono, Stereo, PCM and Passthrough (`Badges/`).

Import URL: `https://raw.githubusercontent.com/jsaxon2/nuvio-badges/main/badges.json`
